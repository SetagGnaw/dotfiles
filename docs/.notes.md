Actually correct form:

```sh
pipx uninstall litellm
uv tool install --force 'litellm[proxy]'
hash -r
which litellm           # should now be ~/.local/bin/litellm via uv
litrestart
tail -f /tmp/litellm.log
```

`uv tool install` puts the entrypoint in `~/.local/bin/` (same path you've been using), so no PATH changes needed.
